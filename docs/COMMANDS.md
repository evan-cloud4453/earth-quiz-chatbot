# 명령어 레퍼런스

모든 명령은 **각 스크립트 상단 `AbleRooms` 배열에 등록된 방에서만** 동작합니다. 등록되지 않은 방에서는 봇이 어떤 반응도 하지 않습니다.

---

## earth-quiz — 메인 퀴즈 엔진

### 진행

| 명령 | 동작 | 비고 |
|---|---|---|
| `ㅈㅋ` | 문제 출제 | 이미 출제된 문제가 있으면 그 문제를 다시 보여 준다 |
| `ㅈㅋㅎㅌ` | 힌트 | 정답에서 아직 안 열린 글자 하나를 무작위로 공개 |
| `ㅈㅋㅈㄷ` | 정답 공개 | 공개 후 상태를 초기화 |
| `ㅈㅋㅇㅇ` | 자동 연속 출제 ON | 정답·정답공개 직후 다음 문제를 자동 출제 |
| `ㅈㅋㄴㄴ` | 자동 연속 출제 OFF | |
| `ㅈㅋㄹㅋ` | 방별 랭킹 | 정답 횟수 내림차순, 1~3위는 메달 |

### 답안 제출

명령이 아닌 일반 메시지는 **정답과 글자 수가 같을 때만** 채점됩니다. 공백·쉼표·마침표는 제거 후 비교합니다.

| 상황 | 봇 반응 |
|---|---|
| 정답 | `🌿 홍길동님 [오르도비스기] 정답! 🌈` + 랭킹 +1 |
| 오답 (2글자 이상) | `☄ 실루리아기 땡! ☄` |
| 오답 (1글자) | 5초간 채점 대상 제외 — `🍭 [홍길동]님 5️⃣초간 🔇!` |

> 1글자 뮤트는 `ㅇ/ㄴ`, 부등호처럼 답이 한 글자인 문항에서 무차별 찍기를 막기 위한 장치입니다.

### 관리자

관리자는 이름이 아니라 **프로필 이미지 해시**로 인증합니다. 닉네임을 바꿔도, 같은 이름으로 사칭해도 통과하지 못합니다.

| 명령 | 동작 | 조건 |
|---|---|---|
| `등록` | 현재 발신자를 관리자로 등록 | `지퀴관리자` 방에서만 |
| `ㅈㅋㅁㅊ` | 해당 방 퀴즈 잠금 | 관리자 |
| `ㅈㅋㄱㄱ` | 잠금 해제 후 바로 출제 | 관리자 |
| `차단 홍길동` | 해당 사용자를 채점 대상에서 영구 제외 | 관리자 |

프로필 이미지를 바꾸면 인증이 깨지므로 `등록`을 다시 해야 합니다.

## quiz-submit — 문항 공모 / 검수

두 개의 덱을 다룹니다. `#` 는 **공모 덱**(`earth-science-submissions`), `%` 는 **정식 덱**(`earth-science`)입니다.

### 등록

```
#대기 대순환은 위도별 에너지 불균형과 ㅁㅁㅁㅁㅁㅁ에 의해 나타난다.#지구자전효과
```

- `ㅁ` 가 빈칸입니다. **`ㅁ` 개수와 정답 글자 수가 정확히 일치**해야 등록됩니다.
- 정답의 공백·쉼표·마침표는 제거 후 저장됩니다.
- 답이 `ㅇ`/`ㄴ` 이면 `(ㅇ/ㄴ)`, `<`/`>`/`=` 면 `(부등호)` 머리말이 자동으로 붙습니다.

| 실패 사유 | 봇 반응 |
|---|---|
| `ㅁ` 가 없음 | 무시 |
| 정답이 비어 있음 | `🍄 답을 입력해주세요!` |
| 빈칸 수 ≠ 정답 길이 | `🍄 빈칸의 길이를 확인해주세요` |

### 조회 · 삭제

| 명령 | 대상 | 동작 |
|---|---|---|
| `#검색#전향력` | 공모 덱 | 정답 일치 🍉 + 문제 본문 포함 🍇 둘 다 검색 |
| `#목록#` | 공모 덱 | 전체 나열 |
| `#삭제#12` | 공모 덱 | 12번 삭제 후 전체 번호 재채번 |
| `%검색%전향력` | 정식 덱 | 위와 동일 |
| `%삭제%12` | 정식 덱 | 위와 동일 |

범위를 벗어난 번호를 넣으면 `🍄 1 ~ N 사이의 번호를 입력해주세요!` 로 거부합니다.

**검수 흐름** — 오픈채팅방에서 `#` 로 공모를 받고 → `#목록#` 으로 훑고 → 부적합한 건 `#삭제#` → 남은 문항을 정식 덱으로 옮깁니다.

## gemini-chat — AI 질의응답

| 명령 | 동작 |
|---|---|
| `? 편서풍 파동이 뭐야` | 새 질문 |
| `! 그럼 제트류랑은 무슨 관계야` | 직전까지의 대화를 함께 실어 보내 맥락 유지 |

- 질문이 10자를 넘으면 "핵심만 짧고 간결하게, 질문자 어조에 맞춰" 라는 지시가 자동으로 덧붙습니다. 카톡에서 긴 답변은 읽히지 않기 때문입니다.
- 대화 버퍼는 최근 6턴까지만 유지합니다. 봇을 재시작하면 초기화됩니다.
- `!` 를 대화 없이 먼저 쓰면 `?` 로 시작하라고 안내합니다.

## welcome — 신규 참여자 환영

명령이 없습니다. 등록된 방에서 **처음 말을 건 사람**에게만 환영 메시지를 보내고, `data/runtime/rooms.json` 에 방별 구성원 명단을 누적합니다.

같은 로직이 `earth-quiz` 안에도 `response_great()` 로 들어가 있습니다. 퀴즈 봇만 단독으로 돌릴 거라면 이 봇은 켜지 않아도 됩니다.

---

## trivia-quiz — 초기 프로토타입

`earth-quiz` 의 원형입니다. 명령 체계는 대체로 같지만 다음이 다릅니다.

- 기본 상태가 **잠김**이라 `ㅈㅋㄱㄱ` 로 먼저 열어야 합니다.
- 잠금/해제에 관리자 인증이 없습니다.
- 힌트가 "문제 문장 안의 빈칸 시작 위치"를 기준으로 동작해 **빈칸이 하나일 때만** 정상입니다. 이 한계 때문에 `earth-quiz` 에서는 정답 문자열 자체를 마스킹하는 방식으로 다시 썼습니다.
- `ㅈㅋ` 연속 입력 시 도배 방지가 걸립니다.

히스토리 기록용으로 남겨 둔 코드입니다.
